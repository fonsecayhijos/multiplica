# Multiplica — Foro de Inversión Inmobiliaria

Web de **Multiplica**: inversión inmobiliaria en Miami y España (Costa del Sol).

## Arrancar en local

```bash
cd Multiplica
npm install
npm run dev
```

Abre http://localhost:3000

En Windows usa **CMD**, no PowerShell.

## Qué incluye

- Fondo blanco, logo centrado
- Fotos Miami + Costa del Sol
- Gráficas de interés por zonas
- Estadísticas de mercado (ilustrativas)
- Embudo de captación para inversores
- Páginas: Inicio, Mercados, Sobre nosotros, Contacto, Legal

## Publicar

Igual que Fonseca: GitHub + Vercel.

## Personalizar

- Email leads: cambiar `info@multiplica.org` en Funnel y Contacto
- Logo: sustituir `public/logo.png`
- Datos de gráficas: `components/MarketCharts.tsx`
